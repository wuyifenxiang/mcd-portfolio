# 麦当劳 MCP 工具返回格式速查

本文件记录本 Skill 实际依赖的工具及其**真实返回格式**。麦当劳 MCP 的多数工具
返回的是给模型看的 Markdown 文本而非纯 JSON，解析时必须按下面这些模式来，
不能想当然。

接入信息：

- 地址：`https://mcp.mcd.cn`
- 传输：Streamable HTTP，`POST` + JSON-RPC 2.0
- 认证头：`Authorization: Bearer <MCP_TOKEN>`
- 限流：单 Token **600 次/分钟**，超出返回 `429`

---

## 1. `now-time-info`

返回体内嵌一段 JSON。取 `data.formatted`。

```
{"success":true,"code":200,...,"data":{"timestamp":1791620539097,
 "datetime":"2026-10-10T16:22:19.097","formatted":"2026-10-10 16:22:19",
 "date":"2026-10-10","dayOfWeek":"SATURDAY","timezone":"GMT+08:00",...}}
```

> 所有倒计时都必须以这个时间为基准，不要用本机时间——本机时区或时钟可能不准。

---

## 2. `query-my-coupons`

入参：`{"page":"1","pageSize":"200"}`（pageSize 上限 200）。

返回纯 Markdown，结构固定：

```
# 您的优惠券列表

共 2 张可用优惠券 | 第 1/1 页 | 每页 200 条

## 招行麦辣鸡腿汉堡通用券
- **优惠**: ¥0 (用券价格)
- **有效期**: 2026-10-06 00:00-2026-11-05 23:59 00:00-04:59 10:30-23:59
- **领取时间**: 4日前收到
- **标签**: 到店专用、外送专用

<img src="..." alt="招行麦辣鸡腿汉堡通用券" ...>
```

解析要点：

- 每张券以行首 `## ` 开头，券名就是该行剩余内容。
- **`有效期` 字段里塞了两段信息**：先是日期区间，后面跟的是**每日可核销时段**。
  以 `2026-10-06 00:00-2026-11-05 23:59 00:00-04:59 10:30-23:59` 为例：

  | 片段 | 含义 |
  |---|---|
  | `2026-10-06 00:00` – `2026-11-05 23:59` | 券的整体有效期 |
  | `00:00-04:59`、`10:30-23:59` | 每天真正能用这张券的时段 |

  天气好的时候读不出差别，但麦辣鸡腿堡券 `10:30` 之前用不了（正餐菜单未开），
  圆筒券 `03:00–04:59` 用不了——**这个时段信息是卡片最有价值的差异化内容**。

- `标签` 里的「到店专用 / 外送专用」决定这张券能不能叫麦乐送。
- 图片是带签名的临时 URL，可能过期，不要把图片地址写进任何长期产物。

## 3. `available-coupons`

无入参。返回麦麦省**可领取**（尚未领取）的券，纯 Markdown，每条的三个字段
以行尾反斜杠续行：

```
### 麦麦省优惠券列表：
- 优惠券标题：免费脆薯饼 \
  状态：可领取 \
  优惠券图片：\
    <img src="https://img.mcd.cn/..." alt="免费脆薯饼" ...>
```

解析要点：

- 用 `优惠券标题：` 起一条，`状态：` 补状态，`<img src=` 取图。
- **同一张券可能重复出现多次**（实测「巧克力味厚松饼猪柳蛋套餐」连续出现 3 条）。
  卡片上要按标题聚合，重复的标成 `×N`，不要把 `len()` 直接当成券种数。
- 这里**没有**有效期字段，所以不能给待领券算倒计时。

---

## 4. `query-my-account`

取 `data.availablePoint`（可用）、`accumulativePoint`（累计）、
`currentMouthExpirePoint`（本月将过期）。

> 字段名里的 `Mouth` 是接口本身的拼写（应为 `Month`），照抄即可，别"纠正"。

新账号通常全是 `0`，属正常现象，不要当成错误。

---

## 5. `campaign-calendar`

入参可选 `{"specifiedDate":"yyyy-MM-dd"}`；不传则返回当月全部活动。

返回 Markdown，按天分组：

```
#### 2026年10月10日 今日

-   **活动标题**：韩式风味蘸酱上新❤️就「酱」心有所「薯」
    **活动内容介绍**：🆕韩式辣椒黄油风味酱
```

解析要点：

- `#### ` 行同时给出**日期**和**状态**（`今日` / `往期回顾` / 未来日期无状态词）。
- 活动标题行是 `**活动标题**：`，紧跟着 `**活动内容介绍**：`。
- **接口按时间正序返回**，直接取前几条会得到最旧的往期活动。卡片要按
  「今日 → 未来（近的在前）→ 往期（新的在前）」重排。
- 文案里含 emoji 和平台特殊字符（如 `𝟗.𝟗`），不要做字符集过滤，原样保留。

---

## 6. `auto-bind-coupons`（写操作）

无入参，一键领取麦麦省当前所有可领券。

**这是本 Skill 唯一的写操作，必须由用户明确同意后才能调用。**
调用后应重新查 `query-my-coupons` 与 `available-coupons` 核对结果。
